# OakNinja's Homebrew Tap

This repository contains Homebrew formulae for OakNinja's projects.

## Available Formulae

### [mm](https://github.com/OakNinja/MakeMe)

`mm` is a CLI tool for interactively selecting and running make targets.

## Usage

To use this tap, run:

```bash
brew tap OakNinja/tap
```

Then you can install any formula from this tap:

```bash
brew install mm
```
